# Legacy analysis outputs

These files were generated by the pre-v2 pipeline. They use a spatial mean of the Tân Châu GloFAS grid and an auxiliary UHSLC tide series, so they are retained only for traceability and must not be presented as validated v2/scientific outputs.

Current QA, features, and model comparisons are under `data/processed/`, `data/features/`, and `data/models/`.
