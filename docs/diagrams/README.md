## Quy ước

- **Công cụ:** diagrams.net (draw.io) — lưu file `.drawio` và export thêm `.png` để chèn báo cáo
- **Font:** Arial hoặc Helvetica (để xuất PDF không bị lỗi font)
- **Màu sắc nhất quán:** Xanh dương cho data flow, xanh lá cho thành phần Web, cam cho DB/PostGIS
